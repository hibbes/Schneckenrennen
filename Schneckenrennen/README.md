# Schneckenrennen

Einfache OOP-Simulation eines Schneckenrennens – Einstiegsprojekt für objektorientiertes Denken.

## Klassen

| Klasse | Beschreibung |
|--------|-------------|
| `Rennschnecke` | Objekt mit Name, Rasse, Höchstgeschwindigkeit; kann kriechen |
| `Rennen` | Verwaltet Teilnehmerliste (ArrayList), Streckenlänge |
| `Main` | Testklasse: Schnecken erstellen, anmelden, kriechen lassen |

## Lernziele

- Objekte modellieren (Attribute + Methoden)
- Konstruktoren und `toString()`-Methode
- `ArrayList<T>` als dynamische Sammlung
- Zufallszahlen mit `Random.nextInt()`

## Weiterentwicklung

Für eine vollständige Rennsimulation (mit Gewinnermittlung, Wettbüro, Schleife bis Ziellinie) siehe **Schneckenrennen_2021**.
